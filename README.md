# Guia Nacionalidade Espanhola para Brasileiros

Site gratuito e independente para brasileiros adultos que moram na Espanha
organizarem o pedido de nacionalidade espanhola por residência (prazo de 2 anos).

🔗 https://nacionalidade.bpsim.com.br

- Site estático: um único arquivo `index.html`, sem servidor e sem cadastro.
- Os dados de cada pessoa ficam só no navegador dela.
- Publicado automaticamente pelo Netlify a cada atualização deste repositório.
- Conteúdo revisado em novembro de 2026. Guia não oficial; não substitui orientação jurídica.
